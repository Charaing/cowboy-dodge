# 총구를 피해라 (Dodge the Barrel)

1인칭 퀵드로우 결투 게임.
카우보이가 총을 허리춤 총집에 넣고 노려보다가, **갑자기 뽑아 왼쪽이나 오른쪽을 겨눕니다.**
**0.2초** 안에 얼굴을 **총구 반대 방향**으로 피하세요.

- 웹캠 얼굴 인식(MediaPipe)으로 머리 위치를 추적합니다. 매 판 시작 전엔 얼굴을 가운데에 두세요.
- 카메라가 없으면 ← → 키로 플레이할 수 있어요.
- 시작 화면에서 반응 시간(0.15~0.7초)을 고를 수 있어요.
- 카우보이가 총을 반쯤 뽑다 다시 넣는 페이크를 써요. 페이크에 움직이면 목숨이 줄어요!

▶ 플레이: https://charaing.github.io/cowboy-dodge/

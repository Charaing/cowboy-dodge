# 총구를 피해라 (Dodge the Barrel)

1인칭 결투 게임. 카우보이가 당신을 겨누고 있습니다.
총구가 흔들리다가 **구멍이 정확히 동그랗게 보이는 순간** 조준된 것 — **0.2초** 안에 머리를 움직여 피하세요.

- 웹캠 얼굴 인식(MediaPipe)으로 머리 위치를 추적합니다. 좌우로 비키거나 숙이면 됩니다.
- 카메라가 없으면 방향키로 플레이할 수 있어요.
- 반응 제한 시간은 주소 뒤에 `?t=0.3` 처럼 붙여서 바꿀 수 있어요.

▶ 플레이: https://charaing.github.io/cowboy-dodge/
